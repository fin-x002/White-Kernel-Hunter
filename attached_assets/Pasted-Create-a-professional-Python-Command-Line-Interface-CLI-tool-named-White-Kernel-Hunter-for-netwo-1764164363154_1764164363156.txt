Create a professional Python Command Line Interface (CLI) tool named "White Kernel Hunter" for network reconnaissance. The tool must be robust, error-free, and styled like a hacker tool.

### Project Structure:
1. `main.py`: The main script.
2. `requirements.txt`: List of dependencies.

### Key Requirements & Features:

1. **Virtual Environment Check:**
   - At the very beginning of the script, check if the user is running inside a Virtual Environment.
   - If NOT in a virtual env, print a warning in RED color: "Error: Please run this tool inside a virtual environment!" and exit.

2. **Advanced ASCII Banner:**
   - On startup, clear the screen and display a beautiful box-style ASCII banner using 'Colorama' (Green or Cyan color).
   - Text inside the banner:
     ╔═══════════════════════════════════════════════╗
     ║             White Kernel Hunter               ║
     ║         Advanced Reconnaissance Tool          ║
     ║             Leader: Babu & Mezushi            ║
     ╚═══════════════════════════════════════════════╝

3. **Dependency Check:**
   - The script should try to import necessary libraries (like `socket`, `threading`, `requests`, `colorama`).
   - If a library is missing, instruct the user to run: `pip install -r requirements.txt`.

4. **Main Menu:**
   - After the banner, ask the user to choose an option:
     [1] Advanced Port Scanner (with Banner Grabbing)
     [2] Subdomain Enum (Basic)
     [3] Exit

### Feature Logic:

**Option [1]: Advanced Port Scanner**
   - Ask for Target IP/Domain.
   - Ask for Port Range (Start and End).
   - Use `Threading` (100 threads) for speed.
   - **Crucial Feature:** When a port is OPEN, do not just print "Open". You MUST establish a connection, send a small byte/trigger, and receive the service banner (e.g., version info).
   - Output format must be: `[+] Port 22 Open : SSH-2.0-OpenSSH_8.2p1 Ubuntu`
   - If no banner is received, print: `[+] Port 80 Open : Unknown Service`

**Option [2]: Subdomain Scanner**
   - Ask for a Target Domain (e.g., google.com).
   - Use a predefined list of common subdomains (e.g., www, mail, remote, blog, webmail, server, admin).
   - Use `requests` library to check if the subdomain exists (HTTP 200 or 403).
   - Output found subdomains in Green.

### File: requirements.txt
   - Include: `colorama`, `requests`.

Make the code clean, well-commented, and use Try-Except blocks to handle keyboard interrupts (Ctrl+C) gracefully.
